## Note on the sponsor categories

These are separate from the global placings, so they're a second shot at winning
with the same submission. Both hardware prizes are per-team-member, which for a
two-person team is a meaningfully better expected value than chasing third place.

Confirm on build day what each sponsor's tooling actually is and what counts as
"use" of it — the material we have names the categories but not the criteria.
