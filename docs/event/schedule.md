# Detailed Schedule

Most cities run from **10:00 a.m.–5:00 p.m. local time**. Check your event page
for exact local timing.

| Time | Activity |
|---|---|
| 10:00–10:30 a.m. | Arrive, check in, grab food, and meet other builders |
| 10:30–11:00 a.m. | Global opening broadcast, challenge briefing, and starter-kit walkthrough |
| 11:00–11:15 a.m. | Form teams and finalize project ideas |
| 11:15 a.m.–3:30 p.m. | **Build** |
| 3:30–4:00 p.m. | Complete project submissions in the portal |
| 4:00–4:45 p.m. | Optional local show-and-tell (after submitting) |
| 4:45–5:00 p.m. | Wrap and group photo |

## What this actually means

**You have 4 hours 15 minutes of build time.** That is the whole budget, and it
includes debugging, deploys, and recording the video.

Suggested internal checkpoints:

| Clock | Target |
|---|---|
| 11:15 a.m. | Idea locked, repo cloned by both of us, env keys working |
| 12:30 p.m. | Thinnest possible end-to-end path runs — ugly is fine, it must *run* |
| 2:00 p.m. | Core interaction works in the real environment, not a mock |
| 2:45 p.m. | **Feature freeze.** Only bug fixes and polish after this |
| 3:00 p.m. | Record the two-minute demo video |
| 3:15 p.m. | Written description + social post drafted |
| 3:30 p.m. | Start submitting — do not wait until 3:50 |

The 3:30–4:00 submission window is not build time. Treat 3:30 as a hard stop.
